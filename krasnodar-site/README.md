# Сайт «Мисс и Миссис Краснодарский край 2027»

Одностраничный сайт конкурса: рассказывает о конкурсе и ведёт в Telegram-бота
[@msmrs_krasnodarskiykray_bot](https://t.me/msmrs_krasnodarskiykray_bot), где
заполняется анкета.

## Оформление

- Цвета: винный `#5A0B17` (фон), тёмно-винный `#42070F` (подвал), красный
  `#8E1527` (лента, акценты), сливочный `#F4E9DC` (текст, кнопки, светлый
  блок «Как подать»), золото `#D2B07A` — только подписи, номера и тонкие линии.
- Все фото тонируются в винный цвет (класс `tone`), чтобы холодные
  блёстки и серый камень не спорили с красным.
- Шрифты: Prata (заголовки) и Jost (текст), лежат в `fonts/`.
- Главный элемент — атласная лента победительницы с надписью конкурса, которая
  протягивается через первый экран при загрузке.
- Фото раскрываются при прокрутке, прокрутка плавная (Lenis, `vendor/`).
  При «уменьшить движение» в системе всё показывается сразу.

## Разделы

Первый экран → О конкурсе → Три категории → Кто может участвовать →
Как подать анкету (4 шага) → Галерея → Призыв подать анкету → Подвал.

## ⚠️ Фотографии — временные

Сейчас на сайте **стоковые фото** с бесплатной лицензией
[Burst by Shopify](https://www.shopify.com/stock-photos/licenses) (авторы:
Samantha Hurley, Thought Catalog и другие). Это не участницы конкурса.
Перед запуском замените их на настоящие фото конкурса — достаточно положить
файлы с теми же именами в `images/`:

| Файл | Где на сайте |
|---|---|
| `hero.jpg`, `hero-mobile.jpg` | Первый экран (компьютер / телефон, вертикальное) |
| `about.jpg` | Блок «О конкурсе» (в арке) |
| `cat-young.jpg`, `cat-miss.jpg`, `cat-mrs.jpg` | Категории |
| `tiara.jpg` | Блок «Кто может участвовать» |
| `g1.jpg` … `g8.jpg` | Галерея |
| `cta.jpg` | Фон финального блока |

## Как менять

Ссылка на бота, дата окончания приёма и контакты — в блоке `SITE` в конце
`index.html`. Пустые контакты не показываются.

## Публикация

Сайт раздаёт nginx с того же сервера, что и бот (`deploy/`). Обновление на
сервере: `cd /opt/krasnodar-bot && git pull`.
