# 🌐 Сайт «Мисс и Миссис Краснодарский край 2027»

Одностраничный сайт (лендинг). Идея оформления — **сцена конкурса и глянцевый
журнал**: красный бархатный занавес открывает сайт и снова сходится в финале,
крупная антиква Playfair Display, номера разделов, тонкие золотые линии.
Золото — только акценты.

## Что на странице

Сцена с занавесом и таймером до конца приёма → 01 О конкурсе → 02 Категории →
03 Требования → 04 Как подать анкету (горизонтальная сцена на компьютере) →
05 Галерея → финал с занавесом → контакты. Все кнопки ведут в бота
[@msmrs_krasnodarskiykray_bot](https://t.me/msmrs_krasnodarskiykray_bot).

Анимации (GSAP + ScrollTrigger, плавная прокрутка Lenis): открытие занавеса,
появление заголовков по словам, «загорание» текста при прокрутке, раскрытие фото
шторкой и параллакс, прорисовка линий, счётчики. Если в системе включено
«уменьшить движение» или скрипты не загрузились — сайт показывается целиком
без эффектов.

## Файлы

- `index.html` — сайт целиком (стили и скрипты внутри);
- `vendor/` — библиотеки анимаций (локальные копии, без внешних CDN);
- `fonts/` — шрифты Playfair Display и Manrope (кириллица + латиница);
- `deploy/` — конфиг nginx.

## Как менять

Всё, что обычно правится, собрано в блоке `SITE` в конце файла:

- `botUrl` — ссылка на бота;
- `deadline` — дата окончания приёма (для таймера);
- `contacts` — Instagram, VK, телефон (пустые не показываются);
- `gallery` — фото прошлых лет: положить файлы в папку `images/` и прописать
  `{ src: "images/имя.jpg", caption: "Подпись" }`.

- `aboutPhoto` — главное фото в блоке «О конкурсе», напр. `"images/about.jpg"`.

## Публикация на сервере

Сайт ставится на тот же сервер, что и бот, через nginx (раздаёт статические
файлы) + бесплатный SSL Let's Encrypt. Нужен домен, указывающий на IP сервера.
