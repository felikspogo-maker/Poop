# 🌐 Сайт «Мисс и Миссис Краснодарский край 2027»

Одностраничный сайт (лендинг) в красно-золотом стиле: один файл `index.html`,
без сборки и внешних библиотек (только шрифты Google Fonts).

## Что на странице

Обложка с золотыми искрами и таймером до конца приёма заявок → бегущая строка →
о конкурсе → категории → требования → 4 шага подачи заявки → галерея прошлых
лет (с просмотром на весь экран) → призыв → контакты. Все кнопки ведут в бота
[@msmrs_krasnodarskiykray_bot](https://t.me/msmrs_krasnodarskiykray_bot).

Анимации: прелоадер с прорисовкой короны, появление блоков при прокрутке,
параллакс, золотая полоса прогресса, 3D-наклон карточек, прорисовка линии шагов,
счётчики. Для пользователей с отключёнными анимациями (настройка системы)
всё показывается сразу.

## Как менять

Всё, что обычно правится, собрано в блоке `SITE` в конце файла:

- `botUrl` — ссылка на бота;
- `deadline` — дата окончания приёма (для таймера);
- `contacts` — Instagram, VK, телефон (пустые не показываются);
- `gallery` — фото прошлых лет: положить файлы в папку `images/` и прописать
  `{ src: "images/имя.jpg", caption: "Подпись" }`.

Фото «О конкурсе» — заменить заглушку в блоке `.frame` на
`<img src="images/about.jpg" alt="...">`.

## Публикация на сервере

Сайт ставится на тот же сервер, что и бот, через nginx (раздаёт статические
файлы) + бесплатный SSL Let's Encrypt. Нужен домен, указывающий на IP сервера.
