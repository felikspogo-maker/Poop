# Сайт «Мисс и Миссис Краснодарский край 2027»

Одностраничный сайт конкурса: рассказывает о конкурсе и ведёт в Telegram-бота
[@msmrs_krasnodarskiykray_bot](https://t.me/msmrs_krasnodarskiykray_bot), где
заполняется анкета.

## Оформление — «Сцена»

- Чёрная сцена, луч софита, винно-красный `#B3172C` и золото `#D2B07A`,
  текст сливочный `#F4E9DC`. Все фото тонируются в винный цвет (класс `tone`).
- Шрифты: Prata (заголовки) и Jost (текст), лежат в `fonts/`.
- Анимации — GSAP + ScrollTrigger, плавная прокрутка — Lenis (всё в `vendor/`,
  с внешних сайтов ничего не грузится):
  - при загрузке раздвигается красный занавес, софит загорается с мерцанием,
    буквы «МИСС / МИССИС» поднимаются, арка с фото раскрывается;
    при повторном заходе в той же вкладке занавес короче;
  - луч софита поворачивается за курсором, в луче летает пыль;
  - ленты с надписями ускоряются при прокрутке;
  - в «О конкурсе» слова загораются по мере прокрутки;
  - категории: при наведении строка загорается и за курсором летит фото
    (на телефоне строка загорается в середине экрана, фото показано сразу);
  - «Что ждёт участниц» на компьютере листается горизонтально;
  - в условиях цифры отсчитываются, ячейки подсвечиваются за курсором;
  - шаги «Как подать анкету» загораются по очереди, линия заполняется;
  - колонны галереи движутся с разной скоростью;
  - в финале рисуется корона и мерцают искры;
  - свой курсор и «магнитные» кнопки (только с мышью).
- Если в системе включено «уменьшить движение», анимаций нет — всё показано сразу.

## Разделы

Сцена → ленты → О конкурсе → Три короны (категории) → Что ждёт участниц →
Кто может участвовать → Как подать анкету → Галерея → Частые вопросы → Финал → Подвал.

## Фотографии

На сайте настоящие фото конкурса (лежат в `images/`). Чтобы заменить фото,
положите новый файл с тем же именем:

| Файл | Где на сайте |
|---|---|
| `hero-crown.jpg` | Первый экран, фото в арке (вертикальное) |
| `interview.jpg`, `hall-stage.jpg` | «О конкурсе» |
| `silver-gown.jpg`, `feather-hat.jpg`, `mrs-crown.jpg` | Категории: Юная Мисс, Мисс, Миссис |
| `host-red.jpg`, `brides-stairs.jpg`, `kokoshnik.jpg`, `red-carpet.jpg`, `coronation.jpg`, `winners.jpg` | «Что ждёт участниц» |
| те же + `gala-table.jpg`, `veils.jpg`, `hall-tables.jpg`, `chandeliers.jpg` | Галерея |
| `coronation.jpg` | Фон финального блока |

## Как менять

Ссылка на бота, дата окончания приёма и контакты — в блоке `SITE` в конце
`index.html`. Пустые контакты не показываются.

## Публикация

Сайт раздаёт nginx с того же сервера, что и бот (`deploy/`). Обновление на
сервере: `cd /opt/krasnodar-bot && git pull`.
