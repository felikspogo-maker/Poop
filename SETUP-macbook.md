# 📖 Установка и запуск бота на MacBook (с нуля)

Полная инструкция: от установки Python до работающего бота с Google-таблицей.
Делай по порядку, ничего не пропуская. Все команды выполняются в приложении
**«Терминал»** (найти: `Cmd+Пробел` → набери «Терминал»).

---

## Часть 0. Устанавливаем Python

Бот написан на Python — его нужно установить один раз.

**0.1.** Проверь, есть ли Python:
```bash
python3 --version
```
- Если видишь `Python 3.10` или выше — переходи к Части 1.
- Если «command not found» — установи Python с
  [python.org/downloads](https://www.python.org/downloads/): скачай `.pkg` для
  macOS и установи как обычную программу. Затем снова проверь командой выше.

---

## Часть 1. Скачиваем код бота

**Вариант А — через Git** (если установлен):
```bash
cd ~/Desktop
git clone https://github.com/felikspogo-maker/Poop.git
cd Poop
git checkout claude/beauty-contest-telegram-bot-etabln
```

**Вариант Б — скачать архивом:**
1. Открой страницу репозитория на GitHub → зелёная кнопка **Code** → **Download ZIP**.
2. Распакуй архив на Рабочий стол (папка `Poop`).
3. В терминале зайди в неё:
```bash
cd ~/Desktop/Poop
```

---

## Часть 2. Создаём Telegram-бота

**2.1.** В Telegram напиши [@BotFather](https://t.me/BotFather) → команда `/newbot`.
Придумай имя и username бота. BotFather пришлёт **токен** вида
`123456789:AAE...` — скопируй его, пригодится в Части 5.

**2.2. Узнай ID организатора** (кому будут приходить заявки): напиши
[@userinfobot](https://t.me/userinfobot), он пришлёт твой числовой **ID**.
Тоже скопируй.

---

## Часть 3. Google Cloud — получаем ключ `credentials.json`

Это «пропуск», по которому бот пишет в твою таблицу. Всё бесплатно, карту
привязывать не нужно.

**3.1.** Зайди на [console.cloud.google.com](https://console.cloud.google.com/)
под своим Google-аккаунтом. Прими условия, если попросит.

**3.2. Создай проект.** Вверху слева список проектов → **New Project** →
имя `russia-earth-bot` → **Create**. Убедись, что вверху выбран этот проект.

**3.3. Включи Google Sheets API.** В строке поиска вверху набери
`Google Sheets API` → открой → **Enable** (Включить).

**3.4. Создай сервисный аккаунт.**
- Меню (☰) → **APIs & Services** → **Credentials**.
- **+ Create Credentials** → **Service account**.
- Имя `bot-writer` → **Create and Continue** → на шагах про роли нажми
  **Continue** и **Done** (роли не нужны).

**3.5. Скачай JSON-ключ.**
- В списке **Credentials** нажми на созданный аккаунт
  (e-mail вида `bot-writer@...iam.gserviceaccount.com`).
- Вкладка **Keys** → **Add Key** → **Create new key** → тип **JSON** → **Create**.
- Файл скачается в «Загрузки». Это и есть `credentials.json`.

⚠️ **Запомни e-mail сервисного аккаунта** — он нужен в Части 4.

---

## Часть 4. Создаём таблицу и открываем доступ

**4.1.** На [sheets.google.com](https://sheets.google.com) создай **пустую
таблицу**, название любое (например «Участницы конкурса»).

**4.2. Скопируй ID таблицы** из адресной строки:
```
https://docs.google.com/spreadsheets/d/1AbCdEf...XYZ/edit
                                        └──── ЭТО ID ────┘
```
Нужен кусок между `/d/` и `/edit`.

**4.3. Дай боту доступ (не пропускай!).**
- В таблице справа вверху → **«Настройки доступа» / Share**.
- Вставь e-mail сервисного аккаунта (`bot-writer@...iam.gserviceaccount.com`).
- Права → **Редактор (Editor)** → сними «уведомить» → **Отправить**.

Без этого шага бот получит ошибку «доступ запрещён».

---

## Часть 5. Складываем файлы на маке

**5.1.** Зайди в папку с ботом (если ещё не там):
```bash
cd ~/Desktop/Poop
```

**5.2. Положи ключ рядом с ботом** и переименуй в `credentials.json`:
```bash
mv ~/Downloads/*.json ~/Desktop/Poop/credentials.json
```
(Если в «Загрузках» несколько json — перетащи нужный в папку `Poop` вручную и
переименуй в `credentials.json`.)

**5.3. Создай файл настроек `.env`:**
```bash
cp .env.example .env
open -e .env
```
Заполни три строки и сохрани (`Cmd+S`):
```
BOT_TOKEN=токен_от_BotFather
ADMIN_CHAT_ID=твой_id_из_userinfobot
GOOGLE_SHEET_ID=id_таблицы_из_шага_4.2
```
Остальное можно не трогать.

## 🚀 Запуск в один клик (проще всего)

Вместо команд из Частей 6–7 можно пользоваться готовыми файлами — они
запускаются **двойным щелчком** в Finder:

- **`setup.command`** — настройка в один клик. Установит всё необходимое,
  спросит токен, ID организатора и ID таблицы и сам создаст файл `.env`.
  Если ключ `credentials.json` лежит в «Загрузках» — предложит скопировать его.
  Запустите этот файл **один раз** (или снова, если нужно поменять настройки).
- **`start.command`** — запуск бота. Двойной щелчок — и бот работает. Чтобы
  остановить, просто закройте открывшееся окно.

> ⚠️ **Первый запуск.** macOS может написать, что файл «от неизвестного
> разработчика». Тогда: правый клик по файлу → **Открыть** → **Открыть**.
> Достаточно сделать так один раз для каждого файла.
>
> Если файлы скачаны архивом ZIP и не запускаются, один раз выполните в
> терминале в папке бота: `chmod +x *.command`

Всё ещё нужно заранее выполнить Части 0–5 (Python, код, токен бота, Google,
ключ и ID таблицы). Файлы `.command` лишь автоматизируют установку и запуск.

## Часть 6. Устанавливаем зависимости и запускаем (вручную)

**6.1. Установка (делается один раз):**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
После `source ...` в начале строки появится `(venv)` — значит окружение включено.

**6.2. Запуск бота:**
```bash
python3 bot.py
```
Строка `Бот запущен. Ожидание сообщений...` означает, что всё работает.

**Остановить бота** — `Ctrl+C` в терминале.

---

## Часть 7. Проверяем, что всё работает

1. Организатор пишет боту `/start` в Telegram — **обязательно**, иначе Telegram
   не даст боту отправлять ему заявки.
2. Подай тестовую заявку: `/apply` → заполни до конца.
3. Проверь три вещи:
   - ✅ организатору в Telegram пришла заявка с фотографиями;
   - ✅ в Google-таблице появилась новая строка;
   - ✅ команда `/table` (у организатора) присылает ссылку на таблицу.

## Запуск бота в следующий раз

Каждый раз, когда открываешь новый терминал:
```bash
cd ~/Desktop/Poop
source venv/bin/activate
python3 bot.py
```

## Если что-то пошло не так

| Симптом | Причина / решение |
|---|---|
| `⚠️ не удалось добавить в Google-таблицу` | Чаще всего забыт **шаг 4.3** — не дал доступ сервисному аккаунту |
| `FileNotFoundError: credentials.json` | Файл не в папке с ботом или назван иначе — см. шаг 5.2 |
| `Не задан BOT_TOKEN` / `ADMIN_CHAT_ID` | Не заполнил `.env` — см. шаг 5.3 |
| Заявки в Telegram есть, а в таблице нет | Неверный `GOOGLE_SHEET_ID` или нет доступа (шаги 4.2 / 4.3) |
| Организатору не приходят заявки | Он не написал боту `/start` (шаг 7.1) |

---

## Важные напоминания

- Бот работает, только пока **открыт терминал** с запущенной командой. Закрыл
  терминал или выключил мак → бот остановился. Уже собранные заявки остаются
  в Google-таблице.
- Файлы `credentials.json` и `.env` — **секретные**. Никому не пересылай и не
  выкладывай в интернет.
- Всё Google-облако для этого бота **бесплатно**, без привязки карты.
