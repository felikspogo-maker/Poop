## Слайд 2: Проблема

### 💡 Консультанты сталкиваются с проблемами:

❌ **60% времени уходит на администрирование:**
- Согласование встреч через email/телефон
- Ручная работа с расписанием
- Конфликты в бронированиях
- Обработка платежей

❌ **Потеря клиентов:**
- 35% клиентов уходят из-за сложности записи
- Нет онлайн-присутствия 24/7
- Отсутствие прозрачности (отзывы, рейтинги)

❌ **Высокие операционные расходы:**
- Аренда офиса
- Административный персонал
- Телефония и коммуникации

### 🎯 Клиенты тоже страдают:

- Сложно найти проверенного консультанта
- Нет прозрачности в ценах и качестве
- Неудобство записи (только в рабочее время)
- Риск мошенничества

---

## Слайд 3: Решение

### 🚀 Комплексная платформа "все-в-одном"

**Для консультантов:**
✅ Автоматическое управление расписанием
✅ Онлайн-прием платежей
✅ Личный кабинет с аналитикой
✅ Мобильное приложение для работы на ходу

**Для клиентов:**
✅ Поиск консультантов по рейтингу и отзывам
✅ Онлайн-бронирование 24/7
✅ Безопасные платежи
✅ Чат с консультантом в приложении

**Ключевая ценность:**
> Экономия 60% времени на администрировании + Рост выручки на 40% за счет доступности 24/7

## Слайд 4: Как это работает

### 📱 User Journey

**Путь клиента:**
1. Скачивает приложение (iOS/Android)
2. Регистрируется за 30 секунд
3. Находит консультанта по специализации
4. Видит рейтинг, отзывы, расценки
5. Выбирает удобное время
6. Оплачивает онлайн
7. Получает консультацию (чат/видео)
8. Оставляет отзыв

**Путь консультанта:**
1. Создает профиль с опытом и услугами
2. Устанавливает расценки
3. Указывает доступность
4. Получает уведомление о бронировании
5. Проводит консультацию
6. Получает оплату автоматически
7. Видит аналитику и статистику
