# 🇨🇳 Бот кастинга «China Fashion Week 2027»

Телеграм-бот [@chinafashionweek_bot](https://t.me/chinafashionweek_bot): принимает анкеты
моделей и пересылает их организаторам в Telegram (без таблиц).

## Анкета (10 шагов, с полосой прогресса)

Согласие на обработку данных → ФИО → возраст → город → рост → размер одежды
(кнопки XS–XL или свой) → опыт дефиле/показов (или «Нет опыта») → Instagram
(ник, ссылка или «Нет») → Telegram (берётся автоматически, если есть @ник) →
телефон (кнопкой) → 3–10 фото (можно альбомом) → проверка → отправка.

## Что ещё умеет

- **Проверка перед отправкой**: можно исправить любой пункт, не начиная заново.
- **Номер анкеты** (№0001, №0002…) и кнопка «📋 Моя анкета» со статусом.
- **Решение организатора прямо под анкетой**: «✅ Пригласить на кастинг» /
  «❌ Отклонить». Отметка появляется у обоих организаторов; при приглашении
  кандидат сразу получает поздравление. Об отказе кандидату не пишется.
- **Повторная анкета** помечается и ссылается на предыдущую.
- Меню: «✨ О кастинге», «📸 Как сделать фото» (памятка по снепам), «💬 Связаться».
- `/stats` — сводка для организаторов.
- Черновики анкет и счётчик сохраняются в `bot_data.pickle` — перезапуск бота
  не сбрасывает недозаполненные анкеты.

## Настройки (`.env`)

```
BOT_TOKEN=токен от @BotFather
ADMIN_CHAT_ID=ID организаторов через запятую
CONTACT_INFO=@ник или телефон для вопросов (необязательно)
```

## Запуск на сервере

Код лежит в общем репозитории `/opt/krasnodar-bot`, бот — в папке
`china-fashion-bot`, служба systemd `china-fashion-bot` (`deploy/`).
Обновление: `cd /opt/krasnodar-bot && git pull && systemctl restart china-fashion-bot`.
