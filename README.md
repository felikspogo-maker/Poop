# 👑 Бот приёма заявок «Мисс и Миссис Россия Земля 2026»

Телеграм-бот для приёма заявок на конкурс красоты **Mrs & Ms Russia Earth**.
Проводит участницу по анкете, собирает данные и фотографии, а затем пересылает
готовую заявку **лично организатору в Telegram**.

## Что делает бот

- 🔒 Запрашивает согласие на обработку персональных данных (ФЗ-152).
- 📝 Пошаговая анкета на русском: ФИ, город, возраст, рост, семейное положение,
  контактный телефон, опыт участия в конкурсах и 5–7 фотографий.
- ✅ Проверяет данные: возраст 14–60 лет, рост от 160 см, минимум 5 фото.
- 🏷 Автоматически подсказывает конкурсную категорию
  (Young Miss / Ms / Mrs / Classic Mrs) по возрасту и семейному положению.
- 👀 Показывает итоговую анкету и просит подтверждение перед отправкой.
- 📤 Пересылает готовую заявку (текст + все фото) организатору в Telegram.
- 📊 Автоматически добавляет участницу в накопительную таблицу Google Sheets,
  доступную организаторам онлайн.

## Категории конкурса

| Категория | Возраст |
|---|---|
| Young Miss Russia Earth 👑 | 14–18 лет |
| Ms Russia Earth 👑 | 18–40 лет |
| Mrs Russia Earth 👑 | 18–45 лет |
| Classic Mrs Russia Earth 👑 | 45–60 лет |

## Установка

> 🍎 **Запускаете на MacBook?** Есть подробная пошаговая инструкция с нуля
> (Python, Google Cloud, таблица, запуск) — см. [SETUP-macbook.md](SETUP-macbook.md).

```bash
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env — укажите BOT_TOKEN и ADMIN_CHAT_ID
```

### Настройка

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`, и скопируйте
   токен в переменную `BOT_TOKEN` в файле `.env`.
2. Узнайте ID организатора, которому будут приходить заявки, через
   [@userinfobot](https://t.me/userinfobot), и впишите его в `ADMIN_CHAT_ID`.
3. Организатор должен **хотя бы раз написать боту** (`/start`), иначе Telegram не
   позволит боту отправлять ему сообщения.

## Запуск

```bash
python bot.py
```

### Через Docker

```bash
docker build -t russia-earth-bot .
docker run --env-file .env russia-earth-bot
```

## Команды бота

- `/start` — информация о конкурсе
- `/apply` — подать заявку
- `/done` — завершить загрузку фото
- `/cancel` — отменить заполнение
- `/help` — помощь
- `/table` — получить ссылку на таблицу участниц (только для организатора)

## Таблица участниц (Google Sheets)

Все заявки автоматически накапливаются в облачной таблице Google Sheets. Каждая
участница — отдельная строка со столбцами: дата, ФИ, город, возраст, рост,
семейное положение, категория, телефон, опыт участия, количество фото, Telegram,
ID и согласие. Ссылку на таблицу можно получить командой `/table`.

### Настройка Google Sheets

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте
   проект и включите **Google Sheets API**.
2. Создайте **сервисный аккаунт**, а для него — **ключ** в формате JSON.
   Скачайте файл и положите рядом с ботом под именем `credentials.json`.
3. Создайте пустую Google-таблицу. Скопируйте её **ID** из ссылки
   `https://docs.google.com/spreadsheets/d/<ЭТОТ_ID>/edit` и впишите в
   `GOOGLE_SHEET_ID` в `.env`.
4. Откройте таблицу → «Настройки доступа» и дайте сервисному аккаунту
   (его e-mail вида `...@...iam.gserviceaccount.com` есть в `credentials.json`)
   права **Редактора**.

Заголовки столбцов и лист «Участницы» бот создаёт сам при первой заявке.

## Структура проекта

```
bot.py           — основная логика, диалог с участницей и пересылка организатору
config.py        — настройки из переменных окружения
categories.py    — определение конкурсной категории
sheets_export.py — накопительная таблица участниц в Google Sheets
```

## Приватность

Фотографии не сохраняются на диск — они сразу пересылаются организатору в
Telegram. Персональные данные участниц хранятся в вашей Google-таблице. Файлы
`.env` и `credentials.json` содержат секреты и не коммитятся (см. `.gitignore`).
