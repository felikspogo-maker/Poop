# 👑 Бот приёма заявок «Мисс и Миссис Россия Земля 2026»

Телеграм-бот для приёма заявок на конкурс красоты **Mrs & Ms Russia Earth**.
Проводит участницу по анкете, собирает данные и фотографии, а затем сохраняет
заявку, пересылает её администратору и (по желанию) отправляет на почту
организаторов.

## Что делает бот

- 📝 Пошаговая анкета на русском: ФИ, город, возраст, рост, семейное положение,
  контактный телефон и 5–7 фотографий.
- ✅ Проверяет данные: возраст 14–60 лет, рост от 160 см, минимум 5 фото.
- 🏷 Автоматически подсказывает конкурсную категорию
  (Young Miss / Ms / Mrs / Classic Mrs) по возрасту и семейному положению.
- 👀 Показывает итоговую анкету и просит подтверждение перед отправкой.
- 💾 Сохраняет заявку с фото в папку `submissions/`.
- 📤 Пересылает готовую заявку администратору в Telegram.
- 📧 Отправляет заявку на почту организаторов (`6408844@gmail.com`) через SMTP.

## Категории конкурса

| Категория | Возраст |
|---|---|
| Young Miss Russia Earth 👑 | 14–18 лет |
| Ms Russia Earth 👑 | 18–40 лет |
| Mrs Russia Earth 👑 | 18–45 лет |
| Classic Mrs Russia Earth 👑 | 45–60 лет |

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env — как минимум укажите BOT_TOKEN
```

### Получение токена

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Скопируйте токен в переменную `BOT_TOKEN` в файле `.env`.
3. Чтобы получать заявки в Telegram, узнайте свой ID через
   [@userinfobot](https://t.me/userinfobot) и впишите его в `ADMIN_CHAT_ID`.

### Почта (необязательно)

Чтобы заявки уходили на почту организаторов, заполните `SMTP_*` в `.env`.
Для Gmail нужен [пароль приложения](https://myaccount.google.com/apppasswords).
Если SMTP не настроен — заявки всё равно сохраняются и пересылаются админу.

## Запуск

```bash
python bot.py
```

### Через Docker

```bash
docker build -t russia-earth-bot .
docker run --env-file .env -v $(pwd)/submissions:/app/submissions russia-earth-bot
```

## Команды бота

- `/start` — информация о конкурсе
- `/apply` — подать заявку
- `/done` — завершить загрузку фото
- `/cancel` — отменить заполнение
- `/help` — помощь

## Структура проекта

```
bot.py          — основная логика и диалог с участницей
config.py       — настройки из переменных окружения
categories.py   — определение конкурсной категории
storage.py      — сохранение заявок на диск
mailer.py       — отправка заявок на почту (SMTP)
```

## Приватность

Папка `submissions/` содержит персональные данные участниц и фотографии —
она добавлена в `.gitignore` и не попадает в репозиторий. Файл `.env` с токеном
и паролями также не коммитится.
